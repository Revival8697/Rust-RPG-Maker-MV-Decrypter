# RPG Maker MV/MZ Decrypter (Rust)

A high-performance, idiomatic Rust port of the RPG Maker MV / MZ Decrypter. Provides multi-threaded parallel batch processing, streaming decryption, memory safety, and automatic key detection.

## Features

- **RPG Maker MV & MZ Format Support**:
  - MV: `.rpgmvp` (PNG), `.rpgmvm` (M4A), `.rpgmvo` (OGG)
  - MZ: `.png_` (PNG), `.m4a_` (M4A), `.ogg_` (OGG)
- **Automatic Key Discovery**:
  - Automatically locates and parses `System.json` to extract `encryptionKey`.
  - Derives the 16-byte XOR key from encrypted PNG headers by comparing them with standard PNG magic signatures.
- **Keyless Image Restoration**:
  - Restores PNG images directly by reconstructing their original headers without needing an encryption key.
- **Parallel Processing**:
  - Multi-threaded file operations powered by Rayon for fast batch decryption across large game asset libraries.
- **Atomic File Operations**:
  - In-place replacements use atomic temporary file writing to protect against incomplete writes or corruption.
- **Dual API**:
  - Full-featured command-line interface (`rpgmv-decrypter`) with structured `--json` output support.
  - Re-usable library crate (`rpgmv_decrypter`) for integration into Rust applications.

## Installation & Build

### Prerequisites
- [Rust toolchain](https://rustup.rs/) (1.70+ recommended, 2021 edition)

### Build Standalone Binary
```bash
cargo build --release
```
The compiled binary will be located at `target/release/rpgmv-decrypter`.

### Run Tests
```bash
cargo test
```

## CLI Usage

### 1. Decrypt Files or Directories
Decrypt a complete RPG Maker project or specific asset directory:
```bash
# Decrypt project directory to an output folder
rpgmv-decrypter decrypt /path/to/game -o /path/to/output

# Decrypt in-place within the game directory
rpgmv-decrypter decrypt /path/to/game --in-place

# Decrypt using an explicit 32-character hex key
rpgmv-decrypter decrypt /path/to/game -k d41d8cd98f00b204e9800998ecf8427e

# Output machine-readable JSON summary
rpgmv-decrypter --json decrypt /path/to/game
```

### 2. Restore PNG Images Without a Key
```bash
rpgmv-decrypter restore /path/to/game/www/img -o /path/to/output
```

### 3. Detect Encryption Key
Detect key from `System.json` or derive it from an encrypted PNG:
```bash
# Auto-detect from game directory or System.json
rpgmv-decrypter detect-key /path/to/game

# Derive key from an encrypted PNG file header
rpgmv-decrypter detect-key /path/to/game/www/img/characters/Actor1.rpgmvp --from-png
```

### 4. (Re-)Encrypt Assets
```bash
rpgmv-decrypter encrypt /path/to/assets -o /path/to/encrypted -k <HEX_KEY>
```

## Library Usage

Add this crate to your `Cargo.toml`:
```toml
[dependencies]
rpgmv-decrypter = { path = "path/to/rpgmv-decrypter", default-features = false }
```

### Example

```rust
use std::path::Path;
use rpgmv_decrypter::{Decrypter, EncryptionKey, FileProcessor, ProcessorOptions};

fn main() -> anyhow::Result<()> {
    let key = EncryptionKey::from_hex("d41d8cd98f00b204e9800998ecf8427e")?;
    let decrypter = Decrypter::new(Some(key));

    let options = ProcessorOptions {
        output_dir: Some(Path::new("output").to_path_buf()),
        in_place: false,
        overwrite: true,
        restore_images: false,
        worker_threads: None,
        progress_callback: None,
    };

    let processor = FileProcessor::new(&decrypter, options);
    let summary = processor.decrypt_all(Path::new("my_rpg_game"))?;
    println!("Processed {} files, {} failed.", summary.files_processed, summary.files_failed);

    Ok(())
}
```

```bash
# Run the built-in library demonstration example:
cargo run --example decrypt_sample
```
